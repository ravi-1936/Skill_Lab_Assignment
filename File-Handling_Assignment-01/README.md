# Python File Handling Assignment

Solutions to four file-handling tasks in `Assignment1.ipynb`.

| # | Task | Input file |
|---|------|-----------|
| 1 | Count words in a file | `document.txt` |
| 2 | Find and replace a word | `data.txt` |
| 3 | Print lines in reverse order | `reverse.txt` |
| 4 | Count lines, words and characters | `stats.txt` |

## How to run
1. Keep all `.txt` files in the same folder as the notebook.
2. Open `Assignment1.ipynb` in Jupyter and run all cells.
